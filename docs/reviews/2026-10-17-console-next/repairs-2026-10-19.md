## 本次修复

| 问题 | 修复结果 | 关键实现 |
|---|---|---|
| 配置同数量改值不冲突 | 预览返回精确目标覆盖及 X-Config-Revision；前端固定预览版本，版本读取失败禁提交；后端在事务锁内比较内容版本，同数量改值也返回 409 | configcenter 的 lane_revision、memory/pg store、AppHandler、SharedConfigEditor |
| 空集合/单 key 写绕过批次窗口 | PostgreSQL 同租户/应用/环境/泳道的单写、删与批次共享事务级 advisory lock，空集合也可串行化；旧计数参数仅作仓储兼容 | configcenter/pg/store.go |
| 泳道空字符串与删除混淆 | 显式区分删除行和合法空字符串；基线删除不偷偷写为空覆盖；预览不回显覆盖值，提交固定实际目标 | SharedConfigEditor |
| Playground 任意模型发 Chat | 目录之外的下拉和直接 URL 同样按能力判断；发送前验证端点并固定请求模型，向量测试有独立验证 | domain/playground、Playground |
| 不完整回答继续污染上下文 | 失败、停止、中断回答排除出后续上下文；SSE 错误帧/损坏 JSON 显式失败，支持 CRLF 事件分隔；结束后取消剩余响应 | domain/playground、Playground |
| Agent 静默丢依赖 | 显式绑定的 Prompt/Skill/KB/工具不可用时阻断并返回可操作错误；不支持的 HTTP/builtin、发现失败或不存在的 MCP 方法不能假装可调用；未绑定的模板变量明确拒绝 | agent/runtime；Agents |
| Agent 前端错误不透明 | Agent 试运行保留独立错误区；原生 SSE 返回结构化错误与正确原始 DONE 帧；网关不在 DONE 后追加裸 JSON；供应商内部错误不原样外泄 | agent/runtime、gateway、ai_bridges、Agents |
| 恢复绕过配额 | 恢复目标创建走相同配额检查/递增，创建失败回退；同一目标重入不重复计数；停止源恢复时目标启动为一副本 | backup_adapters |
| 恢复重复创建/失败无记录 | 必需 Idempotency-Key；先持久化稳定操作和确定目标，再由 Pacer 创建/导入；重试返回同一记录，参数变化 409；进程重启扫描保留目标与名称；运行中的操作不能删除 | backup handler/Pacer、restore_identity、migration 0054、运维页面 |
| 恢复缺校验和读回 | 恢复前比对真实 SHA-256，pg_restore 遇错终止，恢复后读取每张用户表；缺有效校验或非空产物证据不判成功；重试过的 Job 读取成功 Pod 日志，不拿失败 Pod 日志作结果 | backup executor/Pacer |
| 契约不同步 | 从纯内存生产路由构造器导出 OpenAPI，同步前端生成类型；请求版本和必需幂等头进入契约。构造契约不启动 API listener 或 K8s manager | apiroute、main、openapi_contract_test、types.gen.ts |

Agent 的运行策略是“显式引用即必需依赖”；若要停用某项能力，需要先解绑对应资产。当前没有新增通用模板变量输入协议，因此含未绑定变量的模板会明确阻断，未宣称已实现变量渲染。

恢复操作完成代表文件完整性、导入和表可读性检查完成，不等于已经验证任意业务语义或完整灾备体系。恢复仍依据源数据服务规格创建新实例；没有在本次实现跨环境恢复、源实体删除后的独立规格恢复、自动轮换或真实结算。
