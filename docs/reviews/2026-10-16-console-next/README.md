```bash

pnpm --filter @paas/console-user-v2 test:ux
```

- `vue-tsc --noEmit` 与 Vite 生产构建通过。
- ESLint 通过。
- 6 项有行为意义的回归用例通过：列表 null 解包、准确的失败记录深链、全环境基线选择、能力导航可达性、深浅主题关键 token 对比度、命令搜索匹配优先级。

对比度测试只覆盖定义的关键 token，不等于完整 WCAG 合规认证。
