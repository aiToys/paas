# 新版控制台：按用户任务重组的信息架构

日期：2026-10-16。范围：`frontend/console-user-v2`，继续使用 `/next/`；经典版 `/console/`、后端领域与接口不变。

用户本次明确授权重新审视两版组织方式，允许推翻不合理的设计。本设计替代 2026-09-07 稿中关于首页只能是产品列表、低频能力全部放“更多”、产品只能有三个面的限制。组织、产品、服务、环境仍是已有领域概念；导航分组不是新业务实体。

## 对两版的诊断与取舍

| 观察 | 决定 |
|---|---|
| 经典版资源分类完整，但侧栏很长；产品内十五个 tab 混合运行、配置与交付 | 用稳定任务域组织导航；产品内按职责分区 |
| 原新版隐藏了交付中心、工作流和共享配置等入口 | 恢复跨产品交付视图，提供明确 AI 与配置入口 |
| 原新版“交付”把所有管理卡片同时堆在一页，智能研发占据默认首屏 | 默认显示运行记录；研发、变更、流水线、构建、发布、仓库按需进入 |
| 仅靠产品首页会让只调用模型的用户绕路 | 总览提供应用交付与 AI 消费两条平行路径；模型调用不要求先建产品 |
| 全部环境时通过 find 取第一个实例，容易选中其他环境或泳道 | 服务运行按服务 × 具体环境列出全部基线；全局实例可直接打开准确实例 |
| “部署到当前环境”实际只是运行第一个 CD 流水线 | 明确选择流水线与分支，展示配置阶段，不暗示浏览环境会覆盖真实目标 |
| 自写表格缺少列宽、溢出与可访问性约束 | 共用表格、工具栏、分页、空态、错误态和焦点样式 |

## 新导航

```text
工作空间总览：需要关注 / 快速开始 / 我的产品
应用交付：产品 / 交付中心 / 运行实例
AI 平台：模型目录 / Playground / AI 开发
基础设施：数据服务 / 可观测 / 流量治理 / 配置中心 / 环境
组织与访问：密钥与凭证 / API 密钥 / 用量与配额
```

- 产品工作区：服务运行 / 交付 / 共享资源 / 配置 / 成员与权限。
- 产品交付：运行记录 / 智能研发 / 变更与批次 / 流水线 / 构建与镜像 / 发布 / 代码仓库。
- AI 开发：智能体 / 工作流 / 知识库 / 工具 / 提示词 / 技能 / 资源广场 / 执行记录。
- 全局模块提供组织范围的可见性，产品工作区提供具体上下文；两者不是重复的业务实体。
- 导航与快速搜索共用 `src/navigation/index.ts`。精确名称匹配优先，搜索“知识库”直接打开知识库，不停在 AI 首页。

## 视觉与交互基线

1. 中性背景、蓝色操作色、语义状态色；暗色与亮色分别定义 token，不依赖透明度降低文字可读性。
2. 公共 PageHeader、StatePanel、TablePager；正文 14px，常规表格 13px，主要按钮和复制按钮不换行。
3. 搜索、类型、状态与供应商筛选位于列表上方，URL 保留筛选。整组同步避免清除时 query 互相覆盖。
4. 名称和地址过长时省略展示，原值可通过 title 查看；复制始终复制完整地址。环境展示名称而非内部 ID。
5. 表格独立横向滚动；小屏收起导航，支持 Escape、焦点恢复与跳到主内容。保留减少动态效果的系统偏好。
6. 加载失败、未配置、无数据、筛选无结果分别表达。列表 API 的 null 规范为空数组，非数组响应报错；不以错误对象伪装成功空态。
7. 构建通知直达构建日志；运行失败自动展开失败阶段；变更与批次深链携带 focus，定位到准确记录。生产浏览计时与会话过期反馈补齐。

参考模式：[PatternFly 工具栏](https://www.patternfly.org/components/toolbar/)、[PatternFly 表格](https://www.patternfly.org/components/table/react-demos/)、[Carbon 空态](https://www.carbondesignsystem.com/building-blocks/core/patterns/empty-states)。这些是设计依据，不表示完成任何第三方认证。

## 能力迁移与边界

- 在新版内复用经典版成熟的智能体、工作流、知识库、工具、提示词、技能、广场、Playground、环境与泳道、共享配置、安全审计及账单视图；适配新版路由和公共样式。
- 原新版已存在的数据服务创建与详情、产品配置、成员、流水线与运行操作继续保留。
- 后端权限、生产写入校验、CRD 编排、供应商请求与数据库均未重构。
- 本次页面与交互验收不代表 AI 真实推理、流水线部署、生产审批、账单支付或完整商业验收通过。经典版 PR 评审浏览器等未迁入的高级能力不应宣称已全量对等。
