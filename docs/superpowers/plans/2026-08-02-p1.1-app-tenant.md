# P1.1 实施计划：应用去假 + 租户开通

> 2026-08-02 · spec: `docs/superpowers/specs/2026-08-02-p1-real-platform.md`
> 执行方式：inline TDD（每任务 失败测试 -> 实现 -> 通过 -> commit）

## 任务清单

### T1: 应用 seed demo 门控
**目标**：`PAAS_DISABLE_DEMO_SEED=true` 时内存 + PG 两路径均不灌演示应用。

**改动**：
- `internal/core/application/memory/store.go` `NewStore()`：读 env，`true` 跳过 `for _, a := range seed()`。
- `cmd/core/persistence.go` `seedApplications()`：读 env，`true` 直接 return。

**测试**（`memory/store_test.go`）：
- `TestNewStore_DemoDisabled`：`t.Setenv("PAAS_DISABLE_DEMO_SEED","true")` -> `NewStore().List(ctx,"t-acme")` 返空。
- `TestNewStore_DemoEnabled`（默认）：返 5 条（acme 4 + globex 1，或按租户断言数量）。

**验证**：`PAAS_DISABLE_DEMO_SEED=true ./bin/core` -> `curl -H "Authorization: Bearer sk-acme-admin" /api/applications` 返 `[]`。

---

### T2: DeleteTenant 非空保护
**目标**：删租户前检查有用户则 409 拒绝（引导先清用户），防孤儿 + 防误删。

**改动**：
- `internal/core/identity/repository.go`：`Repository` 已有 `ListUsers(ctx, tenantID)`，复用。
- `internal/core/identity/handler.go` `DeleteTenant`：删前 `ListUsers(ctx, id)`，非空 -> 409「租户下仍有用户，请先删除或转移用户」。
- `memory/store.go` `DeleteTenant`：保留现有级联清用户/Key（防御性，前置检查保证无用户，级联无副作用）。
- `pg/store.go` `DeleteTenant`：前置 `SELECT count(*) FROM users WHERE tenant_id=$1`，>0 返 ErrTenantNotEmpty；无用户则 DELETE（FK CASCADE 清 api_keys）。

**测试**（`handler_test.go`）：
- 删空租户 -> 204。
- 删有用户的租户 -> 409，body 含「仍有用户」。
- 错误：定义 sentinel `ErrTenantNotEmpty`，pg `IsTenantNotEmpty` 或直接字符串匹配。

**注意**：跨 store 业务数据（应用/工作负载）级联清留后；P1.1 只防用户孤儿。

**测试**（`menus_test.go` 或 handler_test.go）：`staticMenus()` 含 path=`/system/tenant`。

### T4: 前端 system/tenant api.ts
**目标**：对接 core `/api/tenants`。

**新建** `frontend/console-admin/src/modules/system/tenant/api.ts`：
- `TenantInfo{id, name, createdAt}`。
- `fetchTenantList(): Promise<TenantInfo[]>` -> `GET /api/tenants`。
- `createTenant({id,name}): Promise<TenantInfo>` -> `POST /api/tenants`。
- `deleteTenant(id): Promise<boolean>` -> `DELETE /api/tenants/{id}`。
- 走 `@/lib/http/client` 的 `api` 辅助（与 system/user 同模式）。

### T5: 前端 system/tenant List.vue + FormDrawer
**目标**：租户列表 + 创建 + 删除（危险确认）。

**新建**：
- `frontend/console-admin/src/modules/system/tenant/views/List.vue`：`el-table` 列表（id/name/createdAt/操作）+ 「新建租户」按钮 + 删除（`ElMessageBox.confirm`，输入名称确认）。

### T6: 前端 system/user 创建支持选租户
**目标**：去硬编码 `tenantId:'t-acme'`，super_admin 可选全部租户。

**改动**：

- `system/user/views/UserFormDrawer.vue`：加「所属租户」`el-select`（选项来自 `fetchTenantList()`），默认 t-acme；普通 admin（非 super_admin）锁定本租户禁用选择。

**注意**：super_admin 判定看 `useUserStore` profile.roles 含 `super_admin`。

**目标**：全量验证 + 文档。

**步骤**：

## 执行顺序

T1 -> T2 -> T3 -> T4 -> T5 -> T6 -> T7 -> T8（后端先行，前端依赖菜单+API）。

## 风险

- **DeleteTenant 行为变化**：现状静默级联删用户，改拒绝可能影响依赖此行为的代码（无，删租户仅 admin 手动）。memory 级联保留防御。
- **console-admin 菜单动态加载**：菜单从 core `/api/system/menus` 下发，前端按 `component` 字段动态 import 模块；新加 `system/tenant/views/List` 需确保前端有对应路由组件映射（看 vue-admin 路由生成机制，T5 时确认）。
