- [x] 操作结果：使用现有领域作业记录展示受理/执行/生效/失败；没有终态源就保持未知，不为此重造任务引擎。（R4：受理≠生效文案与操作记录轮询并列）

- [ ] 模型/Key消费归因与跨租户聚合：后端尚无对应维度，不能按已完成勾选。账单凭据、审计和真实结算仍须各自环境验收。
- [x] 审计：后端过滤/分页、失败操作、request/operation关联与脱敏导出；不是在浏览器下载所有审计再过滤。（D4 后端过滤分页 + 97790a1 前端分页补齐）
- [x] 平台诊断：版本、部署模式、迁移、依赖、K8s/RBAC、观测质量与漂移只读检查；安全配置只报状态。（`GET /api/admin/diagnostics`）
- [x] reconcile保留原能力；dry-run新增并验证后再提供预览，执行必须独立确认。（`POST /api/admin/workloads/reconcile?dryRun=true` 只读预览）

验证：适用的领域Go单测/集成测试、后台构建与交互回归。真实供应商探测、集群运维、备份恢复演练、结算动作等列出独立环境验收，不在无授权时执行。HTTP 200不能作为“已生效”验收。
