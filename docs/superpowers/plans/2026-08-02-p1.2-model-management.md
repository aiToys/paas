# P1.2 实施计划：模型管理（Model/Channel/Credential CRUD + admin 页面）

> 2026-08-02 · spec: `docs/superpowers/specs/2026-08-02-p1-real-platform.md`（P1.2 概要）
> 执行方式：inline TDD

## 现状

- `pkg/provider/model.go`：`Model`（ID/Name/Vendor/ContextWindow/Capabilities/InputPrice/OutputPrice/Description/Channels[]）+ `Channel`（ID/Type/Priority/Status/Endpoint/UpstreamModel/CredentialRef + impl `json:"-"`）。
- `internal/maas/catalog.go` + `airouter_catalog.go`：纯函数 `catalog(resolver)` 返硬编码 `[]*provider.Model`，MaaSPlugin.Init 注册到 gateway。
- `internal/core/gateway/gateway.go`：`RegisterModel`（同 ID 覆盖）/`ResolveChannels`/`Models`/`MarkChannelStatus`，无 UnregisterModel。
- 凭证：`security.Secret`（平台级）+ `CredentialResolver.Resolve(ref)`。

## 设计决策

1. **平台级 Store**：Model/Channel 无 tenant_id（模型目录共享，CLAUDE.md 已定）。Store 接口不带 tenant ctx（平台级，与现有 tenant Repository 模式不同）。
2. **Channel.impl 运行时构造**：DB 存 Channel 配置（不含 impl），加载时 `maas.BuildProvider(ch, resolver)` 按 Type 构造 Provider（openai-compatible/mock/echo）+ `SetImpl`。
3. **gateway 增量刷新**：handler CRUD 后调 `RegisterModel`（同 ID 覆盖）/ `UnregisterModel`（新增），不全量重载。
4. **凭证复用 security**：Channel.CredentialRef = security.Secret ID；模型管理 UI 下拉选已有平台级 Secret。
5. **catalog seed 门控**：`PAAS_DISABLE_DEMO_SEED=false`（dev）时 catalog() 灌入 Store 作 demo；生产空，admin 手动配。`catalog()` 函数保留作 seed 真源。
6. **UI**：console-admin「模型管理」（super_admin），模型列表 + 通道配置（CRUD）+ 凭证下拉。

## 风险

- **Channel.impl 刷新**：CRUD 后需重建 impl + RegisterModel，否则 gateway 用旧 Provider。handler 统一调 `reloadModel(id)` 辅助。
- **BuildProvider 凭证缺失**：真实通道无凭证时 Provider 仍构造（Chat 时返 ErrCredentialMissing），不阻断注册。
- **平台级 Store 无 tenant**：与现有 tenant Repository 模式不同，handler 不注 tenant ctx（adminGuard super_admin 兜底）。
- **migration 0016**：需 `make manifests` 无关（maas 非 CRD）；PG 部署需重启 core 跑 migrate。
