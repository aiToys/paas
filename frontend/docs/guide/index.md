# 简介与控制台入口

OnePaaS 围绕应用交付、服务运行与 AI 开发组织资源，提供多租户身份、环境、数据服务、配置与可观测能力。

## 选择入口

| 入口 | 路径 | 用途 |
|---|---|---|
| 经典控制台 | `/console/` | 按应用、DevOps、平台能力组织操作 |
| 新版控制台（试验版） | `/next/` | 按任务域导航，提供产品、交付中心与服务运行视图 |
| 管理后台 | `/admin/` | 平台身份、跨租户资源、模型通道与运维管理 |
| API 参考 | `/api-docs` | Scalar 交互式文档，可填写凭证试调用 |
| 用户文档 | `/docs/` | 安装、操作与排障指南 |

两套用户控制台共用后端资源与权限。本文以新版路径为主，经典版仍可使用；新版的“产品”对应现有 Application 实体和 `/api/applications` API，并未增加一层独立租户或业务对象。

## 新版导航

- **应用交付**：产品、交付中心、工作负载。产品内管理服务运行、交付、共享资源、配置、成员与权限。
- **AI 平台**：模型目录、Playground、AI 开发（智能体、工作流、知识库、工具、提示词、技能、资源广场、执行记录）。
- **基础设施**：数据服务、可观测、流量治理、配置中心、环境。
- **组织与访问**：密钥与凭证、API 密钥、用量与配额。

顶栏环境用于浏览过滤；写操作以资源实际环境或流水线预演的目标为准。切换到测试环境不会改变一条生产流水线的发布目标。

## 能力与依赖

| 能力 | 启用前提 |
|---|---|
| 元数据持久化 | 配置 PostgreSQL；未配置时为内存模式，进程退出后数据不保留 |
| 部署与实例运维 | K8s 数据面可用，具备 CRD 与对应 RBAC |
| 真实构建 | 配置 builder、镜像库及 Git 访问；默认 builder 为 mock |
| 指标、日志、链路 | 分别配置 Prometheus、Loki、Jaeger，并接入应用采集 |
| 模型推理 | 管理员配置可用模型通道、端点和凭证 |
| 知识库 | 配置 Qdrant、MinIO 与 embedding 模型 |
| 智能研发 | 单独接入 AgentRun 执行域；与平台内智能体运行时区分 |

## 运行边界

Go 控制面同源提供四套 SPA、文档站与 API。K8s 工作负载、数据服务由 CRD 期望状态驱动，已落地负载在控制面故障时继续由集群管理；平台 API、经 Core 转发的模型推理及实时发现接口仍依赖控制面。

多租户访问由身份上下文和 Repository 查询过滤约束，生产写操作另需 `prod:write`。交付支持 Helm 与 airsync 离线包；插件契约已提供，当前 MaaS 经插件注册，其他能力在控制面按模块装配。
