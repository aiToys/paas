# 简介

OnePaaS 是面向基础设施的**一站式 PaaS 平台**，以「应用」为主线贯穿开发、测试、发布、运维全生命周期，覆盖：

- **应用主线**——应用 / 环境 / 工作负载 / 泳道
- **DevOps**——代码库 / 构建 / 流水线 / 发布 / 变更管理
- **平台能力**——数据服务 / 服务治理 / 配置中心 / 可观测
- **AI 服务**——模型推理（MaaS）/ 智能体编排

## 平台形态

| 入口 | 路径 | 说明 |
|------|------|------|
| 用户控制台 | `/console/` | 应用开发者日常操作 |
| 管理后台 | `/admin/` | 平台运维（身份 / 推理 / 资源总览） |
| API 文档 | `/api-docs` | Scalar 交互式 API 文档（读 `/openapi.json`） |
| 本文档站 | `/docs/` | 你正在看的页面 |

## 架构速览

- **控制面**：Go 单镜像 `paas-core`，同源 serve 前端与 API（无 CORS）
- **数据面**：K8s 原生资源（CRD 期望状态驱动），控制面故障不影响运行中负载
- **元数据**：PostgreSQL；**事件**：NATS（Core 自带）
- **多租户**：API Key / 会话绑定（租户 × 用户 × 角色），数据层强制隔离，跨租户访问统一 404
- **交付**：Helm + OCI + airsync 离线交付件（SaaS 与私有化双模）
