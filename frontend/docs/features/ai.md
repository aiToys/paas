# AI 开发与编排

新版「AI 开发」包含智能体、工作流、知识库、工具、提示词、技能、资源广场和执行记录。经典版从对应智能体等入口进入。

## 组合业务能力

| 资产 | 用途 | 依赖与检查 |
|---|---|---|
| 智能体 Agent | 模型 + 提示词 + 工具 + 技能组合 | 可用模型通道，显式引用的资产必须存在且可用 |
| 工具 Tool | HTTP / MCP 调用 | 目标网络可达、凭证、工具权限；受 SSRF 防护 |
| 知识库 KnowledgeBase | 文档上传、切片、向量化和检索 | Qdrant、MinIO 与 embedding 模型 |
| 提示词 Prompt | 复用提示词模板 | 模板与参数配置 |
| 技能 Skill | 叠加能力指令 | 当前智能体引用可读取 |

先配置模型，再创建智能体并试运行；引入工具或知识库时逐项验证调用和检索。依赖引用失败会阻断执行并返回错误，不会静默丢弃约束。

## 知识库

管理员配置 `kb.*` 后端及模型通道，上传文档后跟进解析、索引状态。目录 CRUD 可用并不证明上传/向量检索已装配；索引失败先查对象存储、向量维度与模型可用性，再重试。

## 对话、评估与工作流

智能体支持多轮记忆、评估用例与运行记录。工作流按配置组织 LLM、工具、条件、审批及结束等节点，运行状态可持久化，进程重启后恢复推进。

人工审批暂停后，应查看实际输入、建议及将执行的工具动作，再确认或拒绝。恢复推进不等于外部副作用自动具备一次执行保证，实际工具操作仍需业务幂等与结果核验。

发生失败时从执行记录定位模型、资产依赖、工具网络或审批阶段，不把 SSE 错误事件当成成功回答。

## 广场共享

平台级快照发布后不可变，安装时 fork 到租户；快照会剔除凭证。安装后仍需配置自己的可用模型、凭证和依赖，再试运行。广场共享不代表已实现商业交易结算。

## 智能研发执行域

需求生成代码、变更委派和流水线 `agent` 阶段由单独的 AgentRun 执行域提供，需管理员接入；不是平台内业务智能体默认具备的能力。见[智能研发与交付](./agent-delivery)。
