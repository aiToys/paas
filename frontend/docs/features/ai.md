# AI 开发与编排

新版「AI 开发」包含智能体、工作流、知识库、工具、提示词、技能、资源广场和执行记录。经典版从对应智能体等入口进入。

## 组合业务能力

| 资产 | 用途 | 依赖与检查 |
|---|---|---|
| 智能体 Agent | 模型 + 提示词 + 工具 + 技能组合 | 可用模型通道，显式引用的资产必须存在且可用 |
| 工具 Tool | HTTP / MCP 调用 | 目标网络可达、凭证、工具权限；受 SSRF 防护 |
| 知识库 KnowledgeBase | 文档上传、切片、向量化和检索 | Qdrant、MinIO 与 embedding 模型 |
| 提示词 Prompt | 复用提示词模板 | 模板与参数配置 |
| 技能 Skill | 叠加能力指令 | 当前智能体引用可读取 |

先配置模型，再创建智能体并试运行；引入工具或知识库时逐项验证调用和检索。依赖引用失败会阻断执行并返回错误，不会静默丢弃约束。

## Skill 模板与演示

新版「AI 开发 → 技能」提供「我的技能」及「平台模板与对外技能」。知识库问答、结构化结果、故障证据整理是平台指令模板，复制后成为本租户独立副本；重装同一模板保留用户编辑，不自动跟随上游更新。模板版本与内容 hash 可在详情查看。

在「我的技能」选择已启用的条目，点击「绑定试用」，选择已有 Agent 后进入 Playground；推理由用户手动发起。知识库问答还需给 Agent 绑定真实知识库，模板安装不代表索引或模型依赖可用。被 Agent 引用的 Skill 不能直接删除或停用；引用查询失败时阻断此类操作。

平台当前只执行指令注入，不解析任意外部技能包或执行其脚本。接入、应用交付和运行排障三个 OnePaaS 对外 Skill 面向具有 HTTP 能力的外部 Agent。下载文件后放到同名目录的 `SKILL.md`，或使用仓库 `skills/onepaas-*/` 中的标准目录；凭证与操作授权由使用者提供，包中不含演示 Key。

PaasShop 提供 `shop-product-guide`、`shop-order-query` 两个场景，在 `examples/paas-shop/skills/scenarios.json` 定义示例输入、所需工具和检查点。共用安装器 `examples/paas-shop/install_ai.py` 创建 Skill、三个只读 MCP 工具并绑定 `shop-agent`；现有 Skill 指令、模型和 Prompt 保留。安装器管理该演示 Agent 的工具列表，不绑定退款等写方法。两个演示 setup 入口均复用它。安装器本身不发起推理；完整 setup 仍可能按原配置创建负载或流量发生器。

这些只读场景不代表退款业务已具备不可绕过的审批。退款流程、MCP 直调权限和业务端幂等仍需单独验收。

## Skill 加载与链路证据

接入 OTel 采集和 Jaeger 后，Agent 每次读取绑定技能会产生 `paas.skill.load` 子 Span。在新版「可观测 → 链路」展开记录，可查看「Skill 加载证据」，核对技能 ID、名称、实际正文 SHA-256、加载来源、副本更新时间及来源模板版本；「查看加载 Span」可定位对应节点。

来源模板版本描述最初复制的模板，正文哈希描述本轮实际读取的内容；用户编辑后两者可能不同。自建或来源版本未知时显示未提供，不自动生成语义版本。遥测不记录 Skill 正文；哈希是内容指纹，不能用于还原已被覆盖的旧正文。

技能不存在、停用或读取失败会标记加载错误并阻断模型调用。部分技能加载成功后，知识库或工具仍可能准备失败；页面分别显示加载状态与上下文准备状态。加载证据不等于模型已遵循技能或业务执行成功。历史链路不会根据当前绑定补写技能证据；采样、丢失或未上报的记录显示证据缺失。

当前是直接指令注入，`paas.skill.load` 是平台扩展；官方 GenAI Skill 属性和工具操作语义仍处于 Development。平台不将直接注入记录为专门加载工具的 `execute_tool` 操作。

## 知识库

管理员配置 `kb.*` 后端及模型通道，上传文档后跟进解析、索引状态。目录 CRUD 可用并不证明上传/向量检索已装配；索引失败先查对象存储、向量维度与模型可用性，再重试。

## 对话、评估与工作流

智能体支持多轮记忆、评估用例与运行记录。工作流按配置组织 LLM、工具、条件、审批及结束等节点，运行状态可持久化，进程重启后恢复推进。

人工审批暂停后，应查看实际输入、建议及将执行的工具动作，再确认或拒绝。恢复推进不等于外部副作用自动具备一次执行保证，实际工具操作仍需业务幂等与结果核验。

发生失败时从执行记录定位模型、资产依赖、工具网络或审批阶段，不把 SSE 错误事件当成成功回答。

## 广场共享

平台级快照发布后不可变，安装时 fork 到租户；快照会剔除凭证。安装后仍需配置自己的可用模型、凭证和依赖，再试运行。广场共享不代表已实现商业交易结算。

## 智能研发执行域

需求生成代码、变更委派和流水线 `agent` 阶段由单独的 AgentRun 执行域提供，需管理员接入；不是平台内业务智能体默认具备的能力。见[智能研发与交付](./agent-delivery)。
