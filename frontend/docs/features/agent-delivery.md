# 智能研发与交付

智能研发把需求委派到外部 AgentRun 执行域，产生代码分支，再接回平台的构建、测试与发布。它与[平台内智能体和工作流](./ai)的业务对话/工具执行是两类运行路径。

## 接入前提

管理员配置 `PAAS_AGENTRUN_URL`、编排 token 与仓库访问（Helm `agentrun.*`、Gitea 配置），并核对外部执行域权限。未配置时，相关委派/观测入口不可用，agent 阶段会明确失败，不自动完成研发任务。

## 使用路径

1. 在新版「产品 → 交付」的变更中委派智能研发，或使用包含 `agent` 阶段的研发流水线。
2. 填写需求与目标分支上下文，确认执行域和可用仓库。
3. 跟进运行详情、日志与代码产物；检查产生的分支与实际差异。
4. 将产出分支接到后续 build/baseline 等阶段，按交付预演、测试和审批推进。
5. 按仓库评审与发布流程检查代码和运行结果；执行域完成不等于代码已经合入或应用已上线。

平台支持执行记录查看与取消等操作，权限和可用动作以目标部署返回为准。失败时区分：未接入执行域、身份/仓库访问失败、生成执行失败、后续构建或部署失败，再定位对应记录重试。

详见[代码交付](./devops)与[变更管理](./change)。
