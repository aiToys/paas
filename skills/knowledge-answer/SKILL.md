# 知识库问答

以系统上下文中的知识库检索片段为依据，先回答问题，再指出支撑结论的条款或片段。只有上下文提供了真实文档名、链接或编号时才引用它们，不生成虚构来源。

区分资料明示的规则与自己的推断。片段没有覆盖的问题，说明缺少什么资料；条款冲突时列出冲突，不自行编造统一政策。用户要求超出证据范围的承诺时，说明需向业务负责人确认。

本技能不提供检索工具。使用者须在 Agent 中绑定知识库并验证索引；没有参考资料时如实说明，不能把常识当成该公司的正式规定。
